# Москва-иная · Линия судьбы

Версия 5 от 4 октября 2026 года: новый Пузырь в московском дворе, два разных увеличенных портрета Кришенки, яркая золотая гравировка кинжала с искрами; семь сцен, магическая анимация, руны на кинжале, Пузырь и Раста Петрович, изгиб пергамента при перелистывании.

## Публикация на GitHub Pages

1. Распакуйте ZIP-архив.
2. Создайте репозиторий GitHub или откройте существующий репозиторий сайта.
3. Загрузите содержимое архива в корень ветки main, сохранив папку assets. Файл index.html должен находиться непосредственно в корне, а не внутри дополнительной папки. Загружать сам ZIP вместо распакованных файлов не нужно.
4. Сохраните изменения (Commit changes).
5. Откройте Settings → Pages. В Source выберите Deploy from a branch, затем main и /(root). Нажмите Save.
6. Дождитесь окончания публикации. Адрес сайта появится в разделе Pages.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Файлы

- index.html — страницы, текст и ссылка ЛитРес.
- style.css — оформление и адаптация к экранам.
- app.js — управление, перелистывание и магические эффекты.
- assets/ — все иллюстрации.
- .nojekyll — публикация статических файлов без обработки Jekyll.

Сборка, Node.js, серверная часть и API-ключи не требуются. Пути относительные, поэтому сайт подходит для GitHub Pages в подпапке репозитория. Шрифты загружаются из Google Fonts; при отсутствии доступа используются резервные шрифты.

## Локальный просмотр

Из папки с index.html запустите:

    python -m http.server 8000

Откройте http://localhost:8000 в браузере.

## Управление

Колесо мыши, стрелки клавиатуры, кнопки и свайпы. Кнопка «Магия включена» отключает анимацию. При системной настройке уменьшения движения анимация также отключается.
