# Москва-иная · Линия судьбы

Версия 12 от 10 октября 2026 года: процедурное плетение туманных фигур, непрерывное спектральное пламя при сборке голема из ползущих теней, независимые вспышки гравировки кинжала, живые портреты Кришенки и отдельная мобильная композиция с изображением Расты Петровича. Сохранены семь сцен и изгиб пергамента при перелистывании.

## Иной мир

Кнопка в верхней части экрана раскрывает скрытый слой текущей сцены. Каждое новое включение запускает полную сборку заново, даже если предыдущее растворение ещё не закончилось. Выбранный режим сохраняется при перелистывании. Появление на следующей странице начинается после завершения перелистывания.

- В первом портале клубы фиолетового тумана сплетаются в силуэт големши. Перетекающий шум меняет плотность и очертания материала, который продолжает двигаться после появления.
- Над городом облака стягиваются в джина. Полупрозрачный силуэт остаётся нечётким, его края и внутренние складки непрерывно перетекают. Джин вытягивает правую руку вперёд; в открытой ладони проявляется небольшой фиолетовый шар с плавно меняющейся интенсивностью и внутренними световыми течениями. Сияние подсвечивает пальцы и остаётся совмещённым с рукой.
- На мраморной террасе мерцающие тени стекаются по полу к отражению. Переливающиеся языки полупрозрачного пламени поднимаются из них и сплетаются в мрачный контур Бомбо: огонь движется с первых мгновений сборки до полного проявления, затем продолжает скользить по краям фигуры. Образ выполнен в манере кино с реалистичным гримом и костюмом. За основу взят первый пользовательский референс: бледное обезображенное лицо, тяжёлая железная челюсть и ржавые цепи. Костюм состоит из рваного шерстяного пальто, рубашки и брюк с реалистичными складками, прорехами и обтрепавшимися краями. Ржавчина сохраняет приглушённый коричневый оттенок. Тело постепенно набирает плотность снизу вверх и остаётся тёмным, с редкими отблесками мрамора. Глаза и тонкие ветвящиеся вены на сохранившейся коже лица, шеи и рук переливаются фиолетовым. Начальная сборка проходит без россыпи серых искр; полная последовательность занимает около 7,2 секунды.
- У кинжала мерцают отдельные участки настоящей гравировки. Искры имеют разные источники, цвета, скорости, направления и время жизни. Проходящей полосы света нет.
- Големша появляется в тоннеле отдельно от Расты и в дальней арке двора.
- Возвращение постепенно растворяет тело; отражение исчезает последним.
- Кришенка моргает с нерегулярными интервалами, дышит, чуть склоняет голову; отдельные участки волос и свет движутся. Черты лица и веки остаются совмещены. Оба аватара увеличены, анимация работает и в привычном мире.
- На мобильной странице Расты изображение занимает верхнюю часть страницы, подпись находится слева, основной текст — ниже.

Кнопка с символом ✦ ставит движение на паузу. При паузе и системной настройке уменьшения движения кнопка иного мира показывает статическое завершённое состояние. Чтобы увидеть последовательность появления, движение должно быть включено.

## Публикация на GitHub Pages

1. Распакуйте ZIP-архив.
2. Создайте репозиторий GitHub или откройте существующий репозиторий сайта.
3. Загрузите содержимое архива в корень ветки main, сохранив папку assets. Файл index.html должен находиться непосредственно в корне, а не внутри дополнительной папки. Загружать сам ZIP вместо распакованных файлов не нужно.
4. Сохраните изменения (Commit changes).
5. Откройте Settings → Pages. В Source выберите Deploy from a branch, затем main и /(root). Нажмите Save.
6. Дождитесь окончания публикации. Адрес сайта появится в разделе Pages.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Файлы

- index.html — страницы, текст и ссылка ЛитРес.
- style.css — оформление и адаптация к экранам.
- app.js — управление, перелистывание и магические эффекты.
- manifestations.js — WebGL-материалы тумана, облаков, мрамора и спектрального пламени.
- otherworld.js — последовательность проявления, отражение, потоки теней и живые портреты; пространственная маска используется как резерв при отсутствии WebGL.
- otherworld.css — переключатель и мобильные композиции.
- ASSET-PROMPTS.md — описание и промпты новых изображений.
- assets/ — все иллюстрации.
- .nojekyll — публикация статических файлов без обработки Jekyll.

Сборка, Node.js, серверная часть и API-ключи не требуются. Пути относительные, поэтому сайт подходит для GitHub Pages в подпапке репозитория. Шрифты загружаются из Google Fonts; при отсутствии доступа используются резервные шрифты.

## Локальный просмотр

Из папки с index.html запустите:

    python -m http.server 8000

Откройте http://localhost:8000 в браузере.

## Управление

Колесо мыши, стрелки клавиатуры, кнопки и свайпы. Кнопка «Магия включена» отключает анимацию. При системной настройке уменьшения движения анимация также отключается.

## Проверка

    node --check app.js
    node --check manifestations.js
    node --check otherworld.js
    node --test tests/otherworld.test.cjs

Тесты проверяют реальный код рендерера: порядок отражение → тело, непрерывные кривые ленты без мелких искр при сборке, резервную сборку через пространственную маску, использование живого материала, движение пламени с первых мгновений до завершённой фигуры, растворение при возврате, быстрые переключения, ожидание перелистывания и статическое состояние при уменьшении движения.
